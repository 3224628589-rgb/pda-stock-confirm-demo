# PDA 库存确认动态 Demo

[在线体验](https://3224628589-rgb.github.io/pda-stock-confirm-demo/) · [飞书需求](https://sudaornd.feishu.cn/wiki/Ltymwe0oVip46GkWZu8cSUhJn0f?renamingWikiNode=true)

这是需求概览第 4 节「库存确认」的独立前端交互演示。首页沿用既有 PDA「我的」页的橙色视觉与菜单素材；库存确认列表、搜索、处置确认与结果状态为本次新设计。所有订单、商品和库存结果均是合成 Mock，不访问任何后端。

## 使用

直接打开在线链接，点击「我的」页的「库存确认」。也可本地运行：

```bash
npm install
npm start
```

浏览器打开 `http://127.0.0.1:4174`。搜索可试 `6384`、`2026101200016384`、`18`、`氨溴特罗`、`R-05-01-06-06`。`?failOnce=1` 仅用于验证提交失败后的重试。

```bash
npm test
```

## 需求映射

- PDA「我的」新增「库存确认」入口。
- 订单完整号或尾四位、流水号、分拣货位精确搜索；商品名称模糊搜索。销售平台、规格、条码、数量不作为搜索字段。
- 每张卡片展示销售平台、订单号、流水号、商品名称、规格、条码、数量与分拣货位。
- 「找到了，已经放回架上」模拟释放占用库存；「没找到，也没在货架上」模拟系统临时盘点扣除，原因为“机器人分拣途中丢失”。
- 成功后明细移出待确认，数量同步；取消、失败不改库存状态；刷新恢复初始示例数据。

视觉/状态/交互口径见 [docs/contract.md](docs/contract.md)。本 Demo 不接真实 PDA 登录、库存接口、扫码设备或持久化。
