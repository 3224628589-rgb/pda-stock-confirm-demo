# 库存确认 PDA Demo 合同

- 来源：飞书 Wiki `Ltymwe0oVip46GkWZu8cSUhJn0f`，文档 `REC6deCaIod6NcxLDy5cFpyNnfe`，revision 960，需求概览第 4 节“库存确认”（2026-10-12 读取并复核）。
- 视觉：用户提供的 PDA「我的」截图；菜单素材与信息密度参考本机已有「盘点任务下发」PDA Demo。属图片参考重建，不声称像素级复刻。
- 交付：独立 `concept-html`；390×844 PDA 主视口，桌面以设备预览壳展示。不接入真实 PDA、库存或订单接口。
- 作业中心：先找到待确认明细，再判断商品是否已放回架上。主区域是待确认卡片和两项处置，不增加与任务无关的仪表盘。
- 行粒度：本 Demo 按“订单取货明细 × 商品 × 分拣货位”建模。示例数据为合成数据；真实后端幂等、权限和批次库存口径不在本次模拟范围。
- 搜索：订单号完整值或尾四位精确匹配；流水号、分拣货位精确匹配；商品名称模糊匹配。不按销售平台、规格、条码或数量搜索。
- 待确认 → 处理中 → 已释放库存 / 已扣除库存。确认弹层是本 Demo 对不可逆操作的防误触承载；取消不改状态。Mock 请求失败保留待确认并可重试。
- 成功后从待确认列表移除该明细、重算数量。刷新恢复示例初态；未作线上写入。

## 页面与交互矩阵

| 页面/状态 | 来源 | 触发 | 联动结果与恢复 | 验收 |
|---|---|---|---|---|
| 我的首页 | 用户截图 + PRD 4a | 点击「库存确认」整个菜单 | 进入待确认列表；返回保持本会话状态 | 从菜单图标、文字、空白处均可进入 |
| 待确认列表 | PRD 4b/c | 输入搜索词 | 只显示符合规则的待确认明细；清空恢复 | 尾四位/全号/流水/名称/货位各有用例；平台等不召回 |
| 已放回架上确认 | PRD 4d-i + 补充承载 | 点击相应按钮 | 确认后模拟释放占用库存；取消不改变 | 数量和列表同步，连点只处理一次 |
| 未找到确认 | PRD 4d-ii + 补充承载 | 点击相应按钮 | 确认后模拟系统临时盘点扣除，记录原因；取消不改变 | 成功结果明确展示处置方式 |
| 请求失败/重试 | Demo 合成异常状态 | `?failOnce=1` 首次提交 | 明细仍待确认，错误在弹层内，可重试 | 失败不丢明细、不重复扣除 |
| 空态 | 搜索无命中或全部处理 | 搜索/处置完成 | 提供清空搜索或返回我的 | 页面不残留旧卡片 |

静态层级：PDA 顶栏 → 搜索/待确认数 → 可滚动明细 → 底部安全区。确认弹层覆盖在本页面内。桌面旁注只解释操作与 Mock 边界，不属于 PDA 产品界面。
