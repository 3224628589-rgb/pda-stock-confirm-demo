1. 入口：PDA「我的」新增菜单「库存确认」。
2. 搜索框文案：`订单号后四位/流水号/商品名称/货位`。
3. 待确认卡片字段与搜索：销售平台不可搜索；订单号尾四位/全字符串精准搜索；流水号精准搜索；商品名称模糊搜索；商品规格、条码、数量不搜索；分拣货位精准搜索。
4. 卡片按钮：
   - 找到了，已经放回架上：后端释放库存。
   - 没找到，也没在货架上：后端扣除库存；方式为临时盘点，操作人为系统，原因是机器人分拣途中丢失。
